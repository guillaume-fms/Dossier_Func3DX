1) Créer le fichier du user

Create a folder for your user:

Edit user name and email address with correct value:
Save and click on "Yes":

Déclarer le user dans 3DPassport

Declaration in 3DPassport create all the properties of the user: name, country, email, password, etc.
There are two possibilities :
User is not yet registered in 3DPassport -> you will use the action "register"
User is already registered in 3DPassport -> you will use the action "update"
This is the command for local :
sudo /local/opt/factory/3DEXP/3DPassport/linux_a64/code/command/PassportUserImport.sh -default_password Airbus@2018 -default_country "FR" -url http://localhost:8580/3dpassport -admin_username admin_platform -admin_password Passw0rd -action register -file XXXX
​
Avec XXXX qui est le chemin vers le fichier du user qui vient d’être crée ou mis à jour.
This is the command for Int :
sudo /local/opt/dassault/3dexp/3DPassport/linux_a64/code/command/PassportUserImport.sh -default_password Int3-2k18! -default_country "FR" -url https://10.125.122.131:8580/3dpassport -admin_username admin_platform -admin_password Int3-2k18! -action register -file XXXX
​
Avec XXXX qui est le chemin vers le fichier du user qui vient d’être crée ou mis à jour.

Synchronisation

This is the command for local :
sudo sh /local/opt/factory/3DEXP/3DSpace/scripts/OnPremisesSynchroUser.sh -login admin_platform -pwd Passw0rd -users ta-2a64-ta-dev-wgu,ta-2a64-ta-test-wgu
​
Remplacez ta-2a64-ta-dev-wgu,ta-2a64-ta-test-wgu par vos user séparé par une virgule.
