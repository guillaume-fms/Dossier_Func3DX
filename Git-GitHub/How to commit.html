clone the repo distant https://gitlab.factory.eu.airbus.corp/n2h/richclient dans Document/repo
Preparation des files:
les 3DXML (exporter depuis la 3DX)
les fichier codes locaux (fichier en .CATRULE)
le fichier ssc/ResourceSetsToCheck.csv
après changement des differents bindings
se placer sur la branche Develop
git checkout Develop
​
Créer une branche N2H-{{Num de la story}}
git checkout -b N2H-20XXX
​
Appliquer les changements en local
Commit avec num de la story + titre de la story ⇒ N2H-20XXX {{Titre de la story}}
git add .
​
git commit -m "N2H-20XXX XXXXX"
​
Push sur une nouvelle branche du même nom que celle en local
git push --set-upstream origin N2H-20XXX
​
Go on Gitlab and ask for merge
From {{ma branche}} to {{Develop}}
Assigned {{person concerned}}
Check que les changements soient uniquement les miens
Merge !
